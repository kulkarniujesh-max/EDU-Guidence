# EduGuidance

EduGuidance is a student-focused website that helps learners explore education and career options. It brings career field information, entrance exam guides, and related resources together to help students make informed choices.

## Website

- **Live website:** https://kulkarniujesh-max.github.io/EDU-Guidence/
- **GitHub repository:** https://github.com/kulkarniujesh-max/EDU-Guidence

## Features

- Explore careers in arts, commerce, defence, engineering, law, and medicine.
- Browse entrance exam information and exam guides.
- Use the career explorer and AI chatbot pages.
- Create an account and sign in; authentication uses Firebase.
- Save and revisit exam guides.
- Responsive pages for desktop and mobile screens.

## Run locally

This is a static website and does not require a build step.

1. Clone or download this repository.
2. Open `index.html` in a web browser, or serve the folder with any local static file server.

Some account and chatbot features may require Firebase configuration and related service credentials. See [AUTH_SETUP.md](AUTH_SETUP.md) for authentication setup details.

## Main pages

- `index.html` — home page
- `career.html` — career field explorer
- `arts.html`, `commerce.html`, `defence.html`, `engineering.html`, `law.html`, `medical.html` — career field details
- `exam.html` — entrance exam guides
- `chatbot.html` — AI assistant
- `about.html` — about the project team

## Built with

HTML, CSS, and JavaScript, with Firebase used for authentication features.
